A deterministic, stdlib-only Python program that writes one one-line comedy joke (1–280 characters) to `/output/entry.txt`, for make.fun's "One-Liner Marathon" bounty. A deadpan take on AI assistants and privacy: the joke lands on a single line with a surprising punchline, and nothing else.

## Run it

```sh
python3 main.py
```
